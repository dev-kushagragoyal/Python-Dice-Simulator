# Python-Dice-Simulator

Dice-Logic is a Python-based CLI utility that simulates randomized dice outcomes through a structured interface. This script demonstrates the practical application of pseudo-random number generation and persistent loop control within a terminal environment.

The application utilizes the random module to ensure unbiased results and incorporates the time module to manage interaction pacing. By using a series of conditional branches, the program maps specific string responses to each numerical output, creating a responsive user experience.

To use this utility, ensure Python 3.x is installed and run the script via your terminal. Once active, the user can input 1 to execute a roll or 2 to terminate the session. This project serves as a clean example of procedural logic and input handling.
